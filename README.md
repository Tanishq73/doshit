# DoShit

A simple, phone-first habit tracker. Plain HTML, CSS and JavaScript, no build step. Data stays in your browser (`localStorage`).

## Run locally

```bash
python3 -m http.server 5173
```

Then open http://localhost:5173.

## Put it on your phone

1. Host this folder on any static host over HTTPS (GitHub Pages, Netlify, Vercel).
2. iPhone: open it in Safari → Share → Add to Home Screen. Android: Chrome → Install app.
3. It opens full screen and works offline.

Use Settings → Export backup before switching phones or clearing browser data.
